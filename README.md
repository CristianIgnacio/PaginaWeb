# PaginaWeb
Web page that models a platform to send orders, using the
space available in the bags of volunteer travelers.
Voluntary travelers will be able to enter the information of a future trip into the system, informing
the origin and destination, round trip dates, along with the space and kilos available. The
interested in carrying out orders, they will be able to consult in the system the routes that are covered
by the "volunteer travelers" and if they find one that fits the order they want to send,
they can send a request to the volunteer traveler to accept and coordinate the shipment. In this
first version of the system, trips will be considered only between cities that are capitals
of the corresponding countries

Web page made during the course CC5002, "Desarrollo de Aplicaciones Web", of Univeridad de Chile
